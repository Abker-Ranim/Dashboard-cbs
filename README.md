# API Supervision Dashboard

Ce projet est une application web de supervision d'API, développée avec React. Il permet de visualiser et d’analyser les métriques de vos APIs à travers des tableaux et des graphiques interactifs.

## Fonctionnalités

- Visualisation des métriques clés des APIs (requêtes, erreurs, latence, etc.)
- Tableaux dynamiques et filtrables
- Graphiques (lignes, donuts, etc.) pour l’analyse des tendances
- Interface responsive et moderne

## Prérequis

- Node.js >= 14.x
- npm >= 6.x

## Installation

Clonez le dépôt puis installez les dépendances :

```bash
git clone <url-du-repo>
cd api-dashboard
npm install
```

## Lancement en développement

```bash
npm start
```

L’application sera accessible sur [http://localhost:3000](http://localhost:3000).
